# Okayu Issues

Okayu Bot・Okayu Board・Okayu Formsの不具合報告と機能要望を受け付ける公開窓口です。

- [不具合を報告する](https://github.com/bana-okayu/okayu-issues/issues/new?template=bug_report.md)
- [機能を提案する](https://github.com/bana-okayu/okayu-issues/issues/new?template=feature_request.md)
- [対応状況を見る](https://github.com/bana-okayu/okayu-issues/issues)
- [パッチノート](https://okayubot.jp/patch-notes)
- [使い方ガイド](https://okayubot.jp/guide)
- [Okayu Formsのヘルプ](https://form-help.okayubot.jp)

投稿前に、同じ内容のIssueがないか確認してください。投稿にはGitHubアカウントが必要です。
この窓口にはソースコードを置きません。

## 報告するとき

再現手順、期待した動作、実際の動作、使用した端末やブラウザーを記載してください。
スクリーンショットは個人情報を隠して添付してください。

公開された投稿は誰でも閲覧できます。パスワード、Botトークン、認証情報、決済情報、フォームの回答者情報は投稿しないでください。
個人情報を含む相談は[お問い合わせ](https://okayubot.jp/contact)へお願いします。

## 対応とパッチノート

内容を確認し、必要に応じて質問や対応状況をIssueに記載します。
修正が公開されたときに、パッチノートから該当Issueへリンクします。
